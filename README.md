# biz-cockpit-site

Die Produktseite von **Biz-Cockpit** — Verwaltung für kleine Unternehmen.

→ https://marcozwyssig.github.io/biz-cockpit-site/

Dieses Repository enthält **ausschliesslich die Seite**: eine HTML-Datei ohne
externe Abhängigkeiten ausser den Schriften von Google Fonts. Der Code des
Produkts liegt nicht hier und ist nicht öffentlich.

Die Quelle wird im Produktrepository gepflegt (`docs/produktseite.html`) und
hierher kopiert. Wer die Seite ändert, ändert sie dort.
