# biz-cockpit-site

Die Produktseite von **Biz-Cockpit** — Verwaltung für kleine Unternehmen.

→ https://marcozwyssig.github.io/biz-cockpit-site/

Dieses Repository enthält **ausschliesslich die gebaute Seite**. Der Code des
Produkts liegt nicht hier und ist nicht öffentlich.

Gebaut wird sie im Produktrepository mit `./biz-cockpit.sh build website` —
Hugo mit dem Hextra-Thema, in Docker, über den `docs:site`-Task des Kernels.
Die Quellen sind Markdown unter `docs/website/`. Wer die Seite ändert, ändert
sie dort und kopiert das Ergebnis hierher.
